## [1.0.0] - 2022-03-17

First version, as delivered for the school assignment.

### Added

- Memory game with a Swing interface: 4 x 5 grid of cards, move and pair counters.
- MVC structure: `Model`, views (`PanneauImages`, `VueNbCoups`, `VueNbPaires`), controllers (`Controler`, `ControlerBouton`).
- Replay (shuffle) and Quit buttons.
